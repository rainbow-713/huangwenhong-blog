## 第 3 步：把一篇笔记的内容放在一起（约 15 分钟）

**打开哪里：**刚才六行代码后面、`</script>` 前面。

**新增这一段对象数据：**

```js
const note = {
  id: 101,
  title: '认识 HTML',
  summary: 'HTML 用来描述网页结构。'
};
```

把它看成一张有三个栏目的资料卡：

| 栏目，也叫属性名 | 这一篇的值 | 表示什么 |
|---|---|---|
| `id` | `101` | 这条数据的编号 |
| `title` | `'认识 HTML'` | 标题 |
| `summary` | `'HTML 用来描述网页结构。'` | 摘要 |

- `note` 是这份对象数据的变量名。
- `{ ... }` 把属于这篇笔记的信息放在一起。
- 对象中用冒号 `:` 分开属性名和值，属性之间用逗号 `,` 分开。
- 中文标题是文字，放在英文引号里；数字编号 `101` 不加引号。
- 数据的 `id: 101` 不是 HTML 的 `id="note-title"`，它不会自动寻找页面元素。

在这个对象的 `};` 后面，再新增：

```js
console.log(note.title);
console.log(note.summary);
```

`note.title` 就是“取出这篇笔记的标题”，不是把整个对象都显示出来。

**做对时看到：**保存、刷新后，控制台先输出三个元素，然后是“认识 HTML”和摘要；页面仍是占位文字。

**没对上，先检查：**`title` 是否拼错、冒号或逗号是否漏了、文字引号是否成对。控制台出现 `undefined` 通常说明读取的这个属性没有对应值，先检查拼写。

这里的 `{}` 装数据；前两天 `function ... {}` 中的 `{}` 装动作。符号相同，所处位置和用途不同，先结合当前例子理解即可。

## 第 4 步：把数据里的标题和摘要显示出来（约 10 分钟）

**打开哪里：**刚才两个读取属性的 `console.log` 后面、`</script>` 前面。

**新增：**

```js
titleText.textContent = note.title;
summaryText.textContent = note.summary;
```

两行左边是页面显示位置，右边是对象里的值。现在可以画出这一条关系：

```text
note 中的 title → titleText 对应的 h2 → 页面标题
note 中的 summary → summaryText 对应的 p → 页面摘要
```

**做对时看到：**保存、刷新后，页面标题变为“认识 HTML”，摘要变成相应内容；总数仍显示“待计算”。

**没对上，先检查：**
- 页面是 `note.title` 几个字：是不是给 `note.title` 整体加了引号？要取值，不是显示这段代码文字。
- 显示 `[object Object]`：是不是把整个 `note` 放进去了，而不是 `note.title`？
- `note is not defined` 或尚未初始化：对象定义是否写在这两行之前？

`console.log` 只让你在控制台看数据，`textContent` 才修改页面内容。两件事不同。

## 第 6 步：从一篇变成三篇，用数组排在一起（约 20 分钟）

**先留一份成功版本：**保存，在资源管理器里复制 `day03/index.html`，副本命名为 `index-单篇成功.html`。接下来仍改原来的 `index.html`。

**打开哪里：**原 `index.html` 的脚本。下面有两处关联替换，两处都做完再保存、刷新。

### 6.1 只替换单篇对象那一段（约 10 分钟）

找到从 `const note = {` 到对应的 `};`，用下面的数组替换这一整段；保留前面定位元素的六行。

```js
const notes = [
  {
    id: 101,
    title: '认识 HTML',
    summary: 'HTML 用来描述网页结构。'
  },
  {
    id: 203,
    title: '练习 CSS',
    summary: 'CSS 用来调整颜色和间距。'
  },
  {
    id: 305,
    title: '点击按钮',
    summary: 'JavaScript 可以响应点击。'
  }
];
```

- `notes` 末尾多一个 `s`，这里用它表示多篇笔记。
- 外层 `[ ... ]` 是数组，里面按顺序放三个对象。
- 每篇仍是 `{ ... }`，相邻两篇之间也需要逗号。
- 这里用 101、203、305 作为数据编号，是为了提醒你：编号不等于数组位置。

### 6.2 再替换四行“从单篇读取”的代码（约 10 分钟）

原来的下面四行——两个 `console.log(note...)` 和两个 `...textContent = note...`——整体替换为：

```js
console.log(notes[0].title);
console.log(notes[0].summary);
titleText.textContent = notes[0].title;
summaryText.textContent = notes[0].summary;
```

`notes[0]` 取第一篇对象，再用 `.title` 取这个对象里的标题。**数组的位置从 0 开始数。**

| 读取方式 | 取到哪篇 | 这篇的数据编号 |
|---|---|---|
| `notes[0]` | 第一篇“认识 HTML” | 101 |
| `notes[1]` | 第二篇“练习 CSS” | 203 |
| `notes[2]` | 第三篇“点击按钮” | 305 |

**做对时看到：**完成两处替换、保存、刷新后，页面仍显示第一篇的标题和摘要，没有报错。虽然外观相同，数据已从一篇变成三篇。

**没对上，先检查：**
- 报 `note is not defined`：还有旧的 `note.title` 或 `note.summary` 没换成数组读取。
- 报语法错误：检查对象之间的 `},`，以及数组末尾 `];`。
- 不是第一篇：是不是写成了 `notes[1]`？
- 报无法读取 `title`：是不是写成 `notes[101]`？101 是编号，不是这里的数组下标。

```js
totalText.textContent = notes.length;
console.log(notes.length);
```

`notes.length` 是数组长度。在今天这样连续存放笔记的数组里，就是笔记条数，不是标题字数。

**没对上，先检查：**拼写是 `length`，不是 `lenght`；这里没有 `()`，不是 `notes.length()`。不要把 HTML 的“待计算”直接改成固定数字 3。

不需要把总数减一：**三条数据的总数是 3，对应下标是 0、1、2。**

## 常见报错与求助

| 现象 | 优先检查 |
|---|---|
| `Cannot set properties of null` | 三个显示元素的 `id` 是否一致，脚本是否在页面元素后面 |
| 控制台打印 `undefined` | 属性拼写是否一致，例如 `title`、`summary`；下标是否存在 |
| 提到 `Cannot read properties of undefined` | 是否试图从不存在的 `notes[3]` 或 `notes[101]` 上读取标题 |
| `note is not defined` | 从单篇改数组后是否留下旧变量名 |
| `notes is not defined` 或尚未初始化 | 数组定义是否在读取它的代码前面，拼写是否一致 |
| `notes.length is not a function` | 是否给 `length` 多加了 `()` |
| `[object Object]` | 是否把整个对象写进文字，而不是取它的属性 |
| 语法错误指向第二个或第四个对象 | 检查前一个对象结束后是否漏逗号，以及 `{}`、`[]` 是否配对 |
| 控制台变了，页面没变 | 是否只修改了 `console.log`，没有相应修改显示代码 |
| 总数永远为 3 | 是否把总数写死，或新对象放到了数组外面 |
