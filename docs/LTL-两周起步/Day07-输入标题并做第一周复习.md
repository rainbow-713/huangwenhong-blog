## 第 1 步：放一个输入框和预览位置（约 10 分钟）

**打开哪里：**[Vue 官方演练场](https://play.vuejs.org/) 的 `App.vue`。

先把当前 Day06 全部内容保存到 `前端练习/day06/App.vue`。然后用下面起始组件替换演练场练习文件，本地新建 `day07` 留今天成果。

```vue
<script setup>
// 今天的标题数据和动作写在这里
</script>

<template>
  <main class="card">
    <h1>标题预览练习</h1>
    <label for="note-title">笔记标题：</label>
    <input id="note-title" type="text" placeholder="输入一个标题">
    <p>预览：【等待绑定】</p>
  </main>
</template>

<style scoped>
.card {
  max-width: 420px;
  margin: 24px auto;
  padding: 24px;
  font-family: "Microsoft YaHei", sans-serif;
  line-height: 1.6;
  background: #f3f4f6;
  border-radius: 12px;
}
input { box-sizing: border-box; width: 100%; padding: 8px; }
button { padding: 8px 12px; cursor: pointer; }
</style>
```

**做对时看到：**输入框可打字，但预览仍是“等待绑定”。HTML 输入框本来就能接收键盘文字，不代表已经连到了 Vue 数据。

**没对上，先检查：**是否在预览区域打字，而不是在代码中修改输入框；是否有未闭合标签；是否粘进了代码围栏。

`label` 的 `for` 与输入框 `id` 相同，用来关联标签和输入框，不负责把内容放进数据。

## 第 2 步：准备一份字符串数据（约 10 分钟）

**打开哪里：**脚本内，替换提示注释：

```js
import { ref } from 'vue';

const title = ref('');
```

- `''` 是空字符串，两个英文引号之间没有文字，也没有空格。
- `title.value` 是脚本中读写的标题文本。
- `placeholder` 只是输入为空时的提示，不是 `title` 的默认值。

**做对时看到：**页面还没有新的变化；输入框里的字不会因为这两行就自动进入数据。

**没对上，先检查：**引号是否成对；是否把空字符串误写为未定义的变量；`ref` 是否导入。

## 第 3 步：让预览读取标题（约 10 分钟）

**打开哪里：**模板中的预览段落，整行替换：

```html
<p>预览：【{{ title }}】</p>
```

**做对时看到：**预览为 `预览：【】`。输入框即使输入文字，预览也暂时不跟随，因为还没绑定输入。

**没对上，先检查：**插值是否拼对；是否误把 `title` 写成固定文字；当前预览是否因代码重编译刚被重置。

先问自己：“现在模板能读数据，但输入框知道该把字存到哪里吗？”下一步只补这个联系。

## 第 4 步：让输入框与标题数据连接（约 10 分钟）

**打开哪里：**模板里的输入框，整行替换为：

```html
<input id="note-title" v-model="title" type="text" placeholder="输入一个标题">
```

本例的 `v-model="title"` 建立两个方向：
- 用户在输入框输入 → 标题数据更新。
- 标题数据改变 → 输入框显示也更新。

预览的变化来自另一个关系：`{{ title }}` 也在读取同一份数据。不是输入框直接“把字复制到 p 标签”。

**做对时看到：**在预览区域输入“我的笔记”，完成输入后，预览为 `预览：【我的笔记】`；删除最后两个字，预览随之缩短。

**没对上，先检查：**是否写成 `v-model="title.value"`（本例模板直接用顶层 `title`）；输入框和插值是否使用同一个变量。

**中文输入提醒：**拼音输入法还在选候选词的组合输入阶段，预览可能暂时不更新；选词确认后再检查。不要把输入法尚未提交当成绑定失效。今天不加 `.lazy`、`.trim` 等修饰符。

## 第 5 步：用一个动作让两处一起清空（约 15 分钟）

**打开哪里：**脚本中 `const title = ref('');` 后、`</script>` 前新增：

```js
function clearTitle() {
  title.value = '';
}
```

再在模板的预览段落后、`</main>` 前新增：

```html
<button type="button" @click="clearTitle">清空</button>
```

**操作：**先输入“练习 Vue”，确认预览出现，再点击清空。

**做对时看到：**输入框为空，预览为 `预览：【】`。输入框重新出现 placeholder 属于提示文字，不是数据又变成“输入一个标题”。

**没对上，先检查：**按钮函数名；脚本是否改同一个 `title.value`；是否误写 `title.value = ' '`，那是一个空格，不是空字符串。

指代码解释：

```text
键盘输入 → v-model 更新 title → 插值更新预览
点击清空 → clearTitle 修改 title.value
→ v-model 让输入框变空，插值让预览变空
```

两个方向都验证过，才比只说“双向绑定”更能说明理解。

## 第 6 步：只看输入与数据，不急着加功能（约 10 分钟）

依次检查，不改源代码：

| 操作 | 预期 |
|---|---|
| 输入英文 `Vue` | 预览为 `预览：【Vue】` |
| 输入中文并确认候选词 | 预览显示确认后的中文 |
| 在输入框全选并删除 | 预览为 `预览：【】` |
| 输入一段文字后点击清空 | 输入框和预览都空 |
| 连点两次清空 | 仍为空，无报错 |
| 输入前后带空格的 ` Vue ` | 数据保留空格，今天没有自动去空格 |

最后一项不要只凭肉眼判断空格数量：HTML 文本显示可能折叠连续空白。今天只需知道没有使用去空格处理，不把“看起来空白”当成 `''` 的证明；不为此增加字符串长度或校验功能。

## 第 7 步：独立变式——按钮改为填入标题（约 20 分钟）

**先备份：**把清空版的完整组件保存为 `前端练习/day07/App-清空成功.vue`。仍在演练场原文件操作。

**新要求：**将按钮文案改为“填入示例标题”；点击后，输入框和预览都变为“周末练习”。先不要求改函数名，避免同时增加重命名任务。

允许看自己代码和查语法，收起当前题示范：
1. 先预测：按钮应该改哪一份数据，才能让两处一起变？
2. 只改函数中的赋值内容和对应按钮文案。
3. 输入任意文字后点击，应两处都变为“周末练习”。
4. 再在输入框手动改字，预览仍能跟随，不能被按钮永久锁住。
5. 演示后恢复清空版的赋值和文案，保存为最终版。

**卡住时逐条看：**
- 两处是否都依赖同一个 `title`？
- 当前清空是把数据改成什么？改成另一段字符串会怎样？

不用手动操作 DOM，不把预览写死为“周末练习”。挑战未完成时保留尝试与成功版，不让 AI 直接补成品。

## 排错与求助

| 现象 | 先检查 |
|---|---|
| 输入框能打字，预览不变 | 有没有 `v-model`；预览是否插值；是否同一个变量 |
| 预览显示字母 `title` | 是否把数据名当作固定文字 |
| 清空后输入框还有文字 | 输入框是否绑定到这份 title，函数是否正确赋值 |
| 清空后似乎还有空白 | 是否赋值成一个空格 `' '`，而非 `''` |
| 中文选择候选词时暂不更新 | 先提交组合输入再看，不急着改绑定 |
| 刷新后输入没了 | 当前没有持久化，初值为空正常 |

求助时使用本页开头的对应语句。若 AI 已经给出答案，记“示范后完成”，下一次换一个条件再检查。
