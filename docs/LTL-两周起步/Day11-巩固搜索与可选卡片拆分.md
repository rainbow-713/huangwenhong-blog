### 选做 2：子组件只负责展示（约 10 分钟）

在新文件中放入以下完整内容。今天新学的是接收传入数据，不加点击动作：

```vue
<script setup>
defineProps({
  note: {
    type: Object,
    required: true
  }
});
</script>

<template>
  <h2>{{ note.title }}</h2>
  <p>{{ note.summary }}</p>
</template>

<style scoped>
h2 { font-size: 20px; }
</style>
```

- `defineProps` 是 `<script setup>` 的编译宏，无需 import。
- `note` 是约定接收的数据名；这里声明需要一个对象。
- 子组件只读取属性，不在里面给 note 赋新值或删除笔记。
- 子组件没有自己定义一份 notes 数组，数据仍由父组件持有。

此时只创建文件，画面不会自动使用它，这是正常现象。

### 选做 3：父组件导入并传入当前项（约 10 分钟）

在 `App.vue` 脚本 Vue 导入下方新增：

```js
import PracticeNote from './PracticeNote.vue';
```

然后只把原来 article 内连续的标题和摘要两行：

```html
<h2>{{ note.title }}</h2>
<p>{{ note.summary }}</p>
```

替换为：

```html
<PracticeNote :note="note" />
```

外面的 `article v-for`、`:key`、编号显示、删除按钮（如果有）全部保留。不要把整个 article 换掉，否则容易一并丢掉按钮。

**传值关系：**`:note` 左边是子组件接收的 prop 名，右边 `note` 是父循环的当前对象。`note="note"` 少冒号会传固定字符串，不是对象。

- `:key` 仍在列表的 article 上，负责身份对应，不会自动把数据传给子组件。
- 删除按钮留在父组件，仍用 `removeNote(note.id)`，所以今天不需要 emit。
- `.note-card` 外框样式仍在父组件；标题的 h2 样式在子组件自己保留。父组件 scoped 样式不能被当作任意穿透子组件内部的全局样式。

硬前提：数组读取与字符串判断共同支持筛选；输入绑定与筛选共同支持交互搜索；搜索理解与文件定位共同支持安全迁移。组件拆分是软前提，没做也可使用博客已有卡片；新增、删除完整功能也不是搜索迁移的必需前提。

常见卡点与补法：只会命名变量却不会手推结果，补两条数据的真假表；清空后回不来，补“数据被覆盖”和“结果暂时为空”的区别；演练场能做、项目里不知改哪里，按 Day12 文件地图先定位，不重写工程。
