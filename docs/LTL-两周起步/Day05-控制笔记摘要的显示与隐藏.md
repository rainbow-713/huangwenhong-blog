# Day05：控制笔记摘要的显示与隐藏

> 今天只增加一个想法：用一个“是／否”状态，决定摘要是否出现。
> 沿用 Vue 演练场和 `<script setup>`。不加列表、不写动画、不比较一堆指令。

## 开始前的小检查（约 10 分钟）

在演练场打开自己的 Day04：
1. 点击加一、归零，指出 `count.value` 和模板 `count` 的位置。
2. 不改代码，解释为什么点击时不需要手写 `textContent`。
3. 预测归零后再点两次是什么，再验证。

能说明“按钮改数据，模板使用数据，Vue 更新画面”，就继续。若只会念“响应式”，先回 [Day04 第 4～6 步](./Day04-用Vue重做阅读计数器.md) 指出具体对应关系。语法想不起来可以查，不要求默写。

## 今天的终点与节奏

```text
认识 HTML
[切换摘要]
当前开关：false
```

首次点击：开关变为 `true`，出现摘要；再次点击：开关变回 `false`，摘要消失。标题、按钮一直在。

## 第 1 步：准备只有一段摘要的页面（约 10 分钟）

**打开哪里：**[Vue 官方演练场](https://play.vuejs.org/) 的 `App.vue`。先在桌面 `前端练习` 下新建 `day05`，用于保存今天的文件与备份。

1. 先把当前 Day04 内容保存为 `前端练习/day04/App.vue`，确认昨天文件仍在。
2. 再用以下骨架替换演练场 `App.vue`。它是今天的新练习，不覆盖本地 Day04。
3. 保持 JavaScript，不加 `lang="ts"`。

```vue
<script setup>
// 今天的开关数据和动作写在这里
</script>

<template>
  <main class="card">
    <h1>认识 HTML</h1>
    <button type="button">切换摘要</button>
    <p>HTML 用来描述网页结构。</p>
  </main>
</template>

<style scoped>
.card {
  max-width: 420px;
  margin: 24px auto;
  padding: 24px;
  font-family: "Microsoft YaHei", sans-serif;
  line-height: 1.6;
  background: #f3f4f6;
  border-radius: 12px;
}
button { padding: 8px 12px; cursor: pointer; }
</style>
```

**做对时看到：**标题、按钮、摘要都出现。此刻还没有隐藏规则，按钮也没有动作。

**没对上，先检查：**有没有保留旧组件的额外 `<template>`；是否复制了代码围栏；是否在正确的文件里。

## 第 2 步：用布尔值保存“是否显示”（约 10 分钟）

**打开哪里：**脚本内，用下面内容替换提示注释。

```js
import { ref } from 'vue';

const showSummary = ref(false);
```

再到模板中，在按钮后、摘要前新增一行：

```html
<p>当前开关：{{ showSummary }}</p>
```

今天只认识两个布尔值：
- `true`：真，在这里表示显示摘要。
- `false`：假，在这里表示不显示摘要。
- 都不加引号，`'false'` 是文字，不是布尔值；非空字符串用于条件判断会被当作真。

**做对时看到：**开关是 `false`，但摘要暂时仍出现。这不是故障：数据已经存在，模板还没有使用它控制摘要。

**没对上，先检查：**导入和变量名；模板里用 `showSummary`，脚本读写内部值才用 `.value`。

这行开关文字用来观察数据，不是必须发布给访客的产品界面。今天保留它帮助理解。

## 第 3 步：只让摘要按条件出现（约 15 分钟）

**打开哪里：**模板里的摘要段落，整行替换为：

```html
<p v-if="showSummary">HTML 用来描述网页结构。</p>
```

`v-if` 表示“条件为真时，渲染这一块”。本例中：
- `showSummary` 为 `true`：摘要元素出现。
- 为 `false`：这一块不渲染，摘要元素不在页面 DOM 中，不只是文字变透明。

**做对时看到：**开关显示 `false`，摘要不见；标题、按钮仍在。

**没对上，先检查：**是否误把 `v-if` 放在 `<main>` 或按钮上；是否漏了 `v-`；引号内是不是正确的变量名。

做一个小预测：把脚本初值改成 `true`，等重新编译后应该看到摘要。验证后改回 `false`。这是改源码重建初始状态；下一步才是不改源码的运行时切换。

## 第 4 步：让开关变成相反值（约 15 分钟）

**打开哪里：**脚本的 `const showSummary = ref(false);` 后、`</script>` 前。

**新增函数：**

```js
function toggleSummary() {
  showSummary.value = !showSummary.value;
}
```

`!` 是逻辑取反。今天的数据已经是布尔值，所以只需理解：

| 原来的值 | 取反后的值 | 赋回后应看到 |
|---|---|---|
| `false` | `true` | 摘要出现 |
| `true` | `false` | 摘要消失 |

先读右边的旧值、取反，再存回左边。不是每次都固定设为 `true`。

**做对时看到：**函数写好但按钮还未绑定，点击暂时无变化。

**没对上，先检查：**两个位置是否都是 `showSummary.value`；是否漏了 `!`；是否重新声明了另一个开关。

## 第 5 步：绑定点击，观察数据与画面（约 15 分钟）

**打开哪里：**模板里原来的按钮，整行替换为：

```html
<button type="button" @click="toggleSummary">切换摘要</button>
```

先写下“不点、点一次、点两次、点三次”的预测，再不改代码连续点击。

| 点击次数 | 开关 | 摘要 |
|---|---|---|
| 0 | `false` | 不出现 |
| 1 | `true` | 出现 |
| 2 | `false` | 不出现 |
| 3 | `true` | 出现 |

**做对时看到：**开关和摘要同步变化，标题和按钮始终可见。

**没对上，先检查：**
- 开关变了，摘要一直在：摘要有没有 `v-if`？
- 开关没变：按钮是否绑到这个函数，函数是否更新 `.value`？
- 第一次展开后不能收起：是不是每次都赋成 `true`？
- 连按钮也没了：条件是不是放在整个外层上？

指着代码说出原因，不用背定义：

```text
点击 → toggleSummary → 开关取反
→ Vue 重新判断摘要上的 v-if → 出现或不出现
```

## 第 6 步：独立变式——默认就展开（约 15 分钟）

**先备份：**将当前组件保存到 `前端练习/day05/App-基础成功.vue`。仍在演练场原 `App.vue` 中练，不另建组件。

**新要求：**初次打开就显示摘要；第一次点击收起；第二次点击重新展开。保留同一个切换函数。

允许看自己的代码、查语法，收起上面示范。先判断该改“初始状态”还是“每次点击的动作”，再动手。

**验收：**新实例开始 `true` → 第一次点击 `false` → 第二次点击 `true`。不要通过删除 `v-if` 或把函数固定设为 `true` 来实现。

**逐条提示：**
1. 哪一行只决定刚打开时的值？
2. 切换函数已经能在两种状态间来回，是否还需要改？

完成后恢复默认收起的 `false`，保存；若没完成，保留尝试和基础成功版，记下最先不明白的地方。

## 第 7 步：一个可选的对照实验（约 15 分钟）

如果第 6 步还解释不清，就跳过本实验，把时间用于补练。已经完成的人可只在成功版的副本上试一次：

1. 先把当前内容另存 `day05/App-对照实验.vue`，不要覆盖成功备份。
2. 临时把函数内 `showSummary.value = !showSummary.value;` 改成 `showSummary.value = true;`。
3. 预测从 `false` 开始连续两次点击会发生什么，再运行。
4. 预期：第一次展开，第二次仍展开。因为两次都赋为真，不是在切换。
5. 恢复取反语句，验证能来回，再把恢复好的内容保存到 `day05/App.vue`。

**做对的标准：**能说明“固定赋值”和“根据旧值取反”的差别。若只是把代码换回去却说不清原因，先在纸上列两次值变化，不多造几个 bug。

## 第 8 步：检查与提交（约 20 分钟）

| 检查 | 默认收起版预期 |
|---|---|
| 从保存的源码创建新实例 | 开关 `false`，无摘要 |
| 点击两次 | 先出现，再消失 |
| 连续点击多次 | 仍可来回，不会永久失去按钮 |
| 只修改初值为 `true` 后重新运行 | 默认展开，第一次点击收起 |

最后恢复 `false` 作为提交版。演练场热更新可能保留或重建状态；检查默认值时用保存的源码重新创建实例，不用“刚改文件时的旧画面”作结论。分享链接保存的是代码，不是展开状态。

核心理解：
- [ ] 能指出保存开关的变量。
- [ ] 能预测两次点击的结果并说原因。
- [ ] 知道 `v-if` 控制的是哪一个元素。
- [ ] 能区别“默认展开”和“每次都设为展开”。

按照 [Day04 的保存方法](./Day04-用Vue重做阅读计数器.md) 留存 `day05/App.vue` 和可用的分享链接；不要只留浏览器标签页。交文件、一分钟演示和三句说明：

```text
我用______保存开关，______决定摘要是否出现。
```

## 排错与求助

| 现象 | 先检查 |
|---|---|
| 写了 `false` 仍显示摘要 | 是否给 false 加了引号；条件是否写在摘要上 |
| 按钮一起消失 | `v-if` 是否误放在按钮或外层容器 |
| 开关一直为 `false` | 事件函数名、`.value`、是否漏掉赋值 |
| 开关一直为 `true` | 是否用固定赋值代替取反 |
| 只写 `!showSummary.value` 没变化 | 算出了相反值，但有没有存回去 |
| 模板报错 | 当前顶层 ref 在模板不加 `.value`，检查名字和引号 |

今天不追加 `v-show`、`v-else`、三元表达式或动态按钮文案。先让一条条件链清楚。

求助可以说：“Day05 第__步，我预测__，实际__；这是代码。请一次给一个提示，让我指出开关从哪变到哪，不代写组件。”

哥哥只抽查“改初值后第一次点击会怎样”和“固定设为真为什么不能切换”，具体参考 [理解验收指南](./给哥哥-前七天理解验收指南.md)。
