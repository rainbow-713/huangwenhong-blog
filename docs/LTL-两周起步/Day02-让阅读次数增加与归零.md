# Day02：让阅读次数增加与归零

> 今天的需求：一张笔记卡片，点“阅读一次”数字加一，点“归零”恢复为 0。
> 继续用普通 HTML 文件，不学 Vue、不用 npm、不修改博客。今天的次数只是本页练习的计数，不是真实网站访问量。

## 第 2 步：加一个数字位置和一个按钮（约 10 分钟）

**打开哪里：**`day02/index.html` 中的卡片，在摘要后、`</article>` 前面。

**只新增下面两行：**

```html
<p>阅读次数：<span id="read-count" aria-live="polite">0</span></p>
<button id="read-button" type="button">阅读一次</button>
```

保存后切到浏览器，按 `Ctrl+R` 刷新，再点击按钮。

**做对时看到：**显示 0，按钮点击后仍是 0。我们还没添加动作，暂时不变是正常的。

`read-count` 是数字显示位置的名字；`read-button` 是按钮的名字。它们不同，且一个页面里不能重复。

**没对上，先检查：**两行有没有加在卡片内部；有没有多加一份；是否保存、刷新。

## 第 3 步：在程序里保存次数（约 15 分钟）

**打开哪里：**末尾 `<script>` 与 `</script>` 之间。

### 3.1 先找到两个元素（约 5 分钟）

把脚本中的提示注释替换为下面四行。不要再添加一对 `<script>` 标签。

```js
const countText = document.getElementById('read-count');
const readButton = document.getElementById('read-button');
console.log(countText);
console.log(readButton);
```

保存、刷新，在浏览器按 `Ctrl+Shift+J` 打开 Console / 控制台。

**做对时看到：**控制台分别输出 `<span>` 和 `<button>`，不是 `null`。找不到就先对照 HTML 的 `id`，不要继续叠加代码。

### 3.2 保存一个数字，再把它显示出来（约 10 分钟）

在这四行后面、`</script>` 前面新增：

```js
let count = 0;
countText.textContent = count;
```

- `let count = 0`：准备一个名叫 `count` 的变量，当前保存数字 0，后面允许重新赋值。
- `countText`：找到的页面元素；`count`：程序里的数字。它们不是同一个东西。
- `countText.textContent = count`：把当前数字放到页面元素中，浏览器会把它显示成文字。
- 这里用数字 `0`，不是字符串 `'0'`。`let` 这行放在函数外，页面加载时准备一次，后面点击时继续使用。

**做对时看到：**刷新仍显示 0。外观虽没变，但现在程序也有了一份次数数据。

**没对上，先检查：**变量是否写成了 `count`，不是 `'count'`；元素变量是否误写成 `count`；代码是否都在脚本里。

今天只记一个选择：需要重新赋值的次数用 `let`；不用重新指向其他元素的 `countText`、`readButton` 用 `const`。先不学 `var` 和复杂作用域。

## 第 4 步：写“加一，再显示”的动作（约 15 分钟）

**打开哪里：**刚才两行后面、`</script>` 前面。

**新增一个函数：**

```js
function addRead() {
  count = count + 1;
  countText.textContent = count;
}
```

先不用点击，按这个顺序理解两行：

1. `count = count + 1`：先取旧次数，加 1，再把结果存回 `count`。
2. `countText.textContent = count`：把新次数写到页面中。

`=` 在这里表示赋值，不是数学等式。假设旧值是 2，右边算出 3，左边就保存 3。

| 点击前保存的数字 | 加一后保存的数字 | 应该显示 |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 2 | 2 |
| 2 | 3 | 3 |

**做对时看到：**保存、刷新后还是 0，点击仍不变，因为函数还没与按钮连接。

**没对上，先检查：**`let count = 0` 是否留在函数外；函数里的两行顺序是否一致；括号、英文标点是否配对。

不要把 `let count = 0` 搬进 `addRead` 里，否则每次点击都重新从 0 开始。今天也先不把加一改写成 `++`，能读懂这两步就够了。

## 第 5 步：让每次点击都执行加一（约 10 分钟）

**打开哪里：**`addRead` 函数结束的 `}` 后面，仍在 `<script>` 内。

**在函数外新增：**

```js
readButton.addEventListener('click', addRead);
```

`addRead` 后面不加 `()`：把动作交给按钮，等点击时再执行。

**检查动作：**保存、刷新 → 点击一次 → 再点一次 → 再点一次。

**做对时看到：**0 → 1 → 2 → 3，没有每点击一次就刷新网页。

**没对上，先检查：**
- 一直是 1：有没有在函数内重新写 `count = 0`，或直接写 `count = 1`？
- 变成 `01`、`011`：是不是把数字 0 写成了字符串 `'0'`，或直接用页面文字与 1 相加？
- 没点击就显示 1：监听处是否误写成 `addRead()`？
- 一点就加两次：函数里是否写了两条加一语句，或另外绑定了其他加一动作？

这里用单独的数字变量做计算，不用 `countText.textContent + 1`。页面的 `textContent` 读出来是文字，拿它直接加 1 容易变成拼接。

## 第 6 步：再加一个归零按钮（约 10 分钟）

**打开哪里：**卡片 HTML 里原来的“阅读一次”按钮后面、`</article>` 前面。

**新增一行，不替换原按钮：**

```html
<button id="reset-button" type="button">归零</button>
```

再到 `<script>`，在 `const readButton = ...` 那一行后面新增：

```js
const resetButton = document.getElementById('reset-button');
```

**做对时看到：**保存、刷新后有两个按钮；“阅读一次”仍能加一，“归零”暂时无反应。

**没对上，先检查：**新按钮 `id` 是否唯一；新变量是否是 `resetButton`；是否不小心覆盖了 `readButton`。

你在做的是昨天“恢复未读”的同类动作：新按钮有新名字，但仍操作同一个显示位置。

## 第 7 步：归零要同时改数据和显示（约 15 分钟）

**打开哪里：**脚本末尾，原有加一函数和监听都保留。

### 7.1 新增一个归零动作

在原有代码后、`</script>` 前面新增：

```js
function resetRead() {
  count = 0;
  countText.textContent = count;
}
```

先把程序里的次数变为 0，再把 0 显示出来。不要只改页面上的字。

### 7.2 在新函数外连接点击

在这个函数的 `}` 后面新增：

```js
resetButton.addEventListener('click', resetRead);
```

**做对时看到：**保存、刷新；加三次显示 3；归零显示 0；再加一次显示 1。

**没对上，先检查：**
- 显示归零了，但下次一加变成 4：只改了显示，漏掉 `count = 0`。
- 程序已经归零但页面仍显示 3：漏掉更新 `textContent`。
- 没反应：检查新按钮的变量、函数名、监听，以及控制台第一条红字。

### 按顺序走完，不在中间刷新

| 操作 | 预期数字 |
|---|---|
| 刷新后，还没点 | 0 |
| 先归零 | 0 |
| 阅读一次，连点三次 | 3 |
| 归零 | 0 |
| 再阅读一次 | 1 |
| 再归零两次 | 0 |
| 阅读一次，随后刷新 | 刷新前 1，刷新后 0 |

刷新会重新执行 `let count = 0`。今天没有保存历史次数，归零是正常现象，不加数据库或浏览器存储。

## 第 8 步：独立变式——每次加二（约 20 分钟）

**先备份：**确认基础版能加一、能归零。在资源管理器中复制 `day02/index.html`，把副本命名为 `index-基础成功.html`。继续修改原 `index.html`，副本不动。

**打开哪里：**自己的 `day02/index.html`，收起本页加一动作的示范，可以查语法、看自己代码。

**新要求：**
1. 将按钮文案改为“增加两次”。
2. 每点击一次增加 2，不是把次数固定变成 2。
3. 归零后再点，应显示 2。

先写下预测：从 0 开始，连点三次应显示什么？归零后再点一次呢？再改代码验证。

**验收结果：**0 → 2 → 4 → 6；归零 → 0；再点 → 2。演示后把按钮文案和加法改回加一版，保存并再次验证，方便 Day04 对照复现。

**卡住时逐条看提示：**
- 哪个函数决定“增加多少”，哪个函数只负责归零？
- 应该改计算中的数字，还是初始次数？
- 你是改变每次增加量，还是给变量固定赋了一个值？

用了提示就如实记录。仍不懂时，保留尝试，打开备用的基础版，先用纸推演“旧值 0、1、2 各加 1”的结果。不要追加减一、下限、输入框这些新要求。

## 排错与求助

| 现象 | 先看哪里 |
|---|---|
| 改了没有变化 | 保存、刷新、当前文件是否为 `day02/index.html` |
| `null` 或提到 `textContent` 的报错 | HTML 的 `read-count` 与 JS 定位名字是否一致，脚本是否在卡片后面 |
| `Assignment to constant variable` | 次数是否误写成 `const count`；会重新赋值的次数用 `let` |
| `already been declared` | 是否重复输入了 `let count` 或某个 `const` 声明 |
| 次数永远为 1 | 是否在点击函数里重新初始化，或赋了固定的 1 |
| `01`、`011` | 是否把数字写成字符串，或使用页面文字进行加法 |
| 点击没反应 | 函数有没有绑定；名字一致吗；第一条报错是什么 |
| 显示归零但下次加成 4 | 归零函数是否漏了 `count = 0` |

控制台：浏览器按 `Ctrl+Shift+J`。复制第一条报错和相关代码，不用自行看懂全部英文。
