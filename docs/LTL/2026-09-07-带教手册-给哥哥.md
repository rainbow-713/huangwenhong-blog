# 带教手册（给哥哥）

> 你是 8 年后端，但这活儿是"带前端小白 15 天冲刺实习一面"。这份手册把你的经验**结构化**，让你带得有章法。
> **她做的那套**（不含你要干嘛）：《预备篇》《15 天每日任务清单》《面试题库-背诵版》《面试包》《认知地图》。
> **这份《带教手册》是你专属的**，只放你要做的事，她那份里不会出现。

---

## 0. 你的角色：教练，不是替考

- 你最大的风险是"看她写得慢/写得烂，忍不住自己上手"——**忍住**。你替她敲的每一行，
  面试时都会变成她答不出的坑。
- 目标不是"把项目做完美"（项目已经够好了），是"**让她能讲、能改、能写**"。
- 别再优化项目，去优化**人**。

---

## 1. 核心教学法：五步循环（每个知识点 / 每段代码都这么过）

1. **你讲一遍**：1-2 句人话，别堆术语
2. **让她复述**：说不出 = 没懂，重讲
3. **让她手敲**：不看你的，敲进项目里
4. **让她改**：改个变量 / 加一行 / 换个写法，验证她真懂
5. **你抽查**：隔天、隔几天再问一次，对抗遗忘

> 判断标准：**能讲清楚 + 能改 + 隔天还记得 = 真会。只会背原话 = 假会。**

---

## 2. 每天你怎么带（你要上班：改成"她白天自学 + 你晚上/周末把关"）

白天她跟着《预备篇》和《15 天每日任务清单》自己做——概念解释、手敲步骤、手写题、要背的题都写在文档里，
不用等你。你只在两个时间点介入：

| 时段 | 你的动作（每天 30-60min 就够） |
|---|---|
| 晚上回家 | ① 抽查今天的手写题（随机 2-3 道，白纸写给你看）② 让她复述今天学的概念 ③ 追问"为什么/那如果…" |
| 周末 | 组织一次完整模拟面试（见第 5 节）+ 集中补这周弱项 |

> 关键：**文档要能替你"讲"**。《手把手》里每步都写了大白话解释，她卡住先看文档，
> 实在不懂记进"问题本"晚上问你。你不在也能推进——这是计划能落地的前提。

---

## 3. 考官弹药（你的核心价值）

每个考点三行：**一句话标准答案 / 常见追问 / 她必须达到的深度**。照着问，答不到深度就重讲。

### CSS

- **盒模型**：内容 + padding + border + margin ｜ 追问：`box-sizing:border-box` 干嘛的、margin 合并 ｜ 深度：能画出来、能说 border-box 让 width 包含 padding+border
- **Flex 居中**：`justify-content` 主轴 + `align-items` 交叉轴居中 ｜ 追问：`flex:1` 什么意思、主轴方向怎么改 ｜ 深度：**能现场写出水平垂直居中**
- **移动端适配**：`@media` 断点，一套页面适配大小屏 ｜ 追问：为什么用 rem/vw、断点怎么定 ｜ 深度：能讲博客里的 `@media (max-width:768px)`

### JavaScript

- **var/let/const**：var 函数作用域 + 变量提升，let/const 块级作用域，const 不可重新赋值 ｜ 追问：const 对象能改属性吗（能）｜ 深度：能说块级作用域解决了什么
- **箭头函数**：简写 + 不绑定自己的 this ｜ 追问：什么时候不能用（需要 this 的场景、构造函数）｜ 深度：能说 this 指向区别
- **`==` vs `===`**：`===` 严格比较类型+值，`==` 会隐式转换 ｜ 追问：`[]==false` 吗、`null==undefined` 吗 ｜ 深度：能举一个 `==` 的坑
- **Promise**：异步解决方案，then/catch，三态 pending/fulfilled/rejected ｜ 追问：async/await 和它的关系、怎么并发多个（`Promise.all`）｜ 深度：能写一个简单 Promise 链
- **深浅拷贝**：浅拷贝只复制一层、深层仍是引用；深拷贝递归复制全部 ｜ 追问：`JSON.parse(JSON.stringify())` 的局限（函数/undefined/Date/循环引用）｜ 深度：**能手写递归深拷贝**
- **闭包**：函数记住并访问定义时的作用域，即使在外面执行 ｜ 追问：有什么用/有什么问题（私有变量、内存泄漏）｜ 深度：能举例——防抖里的 `timer` 就是闭包

### Vue

- **响应式原理**：Vue3 用 Proxy 劫持数据，数据变了自动通知依赖更新视图（**一句话就够**）｜ 追问：Vue2 用什么（defineProperty）、为什么换 Proxy ｜ 深度：能说 Proxy 强在哪（能监听新增/删除/数组下标）
- **ref vs reactive**：ref 包基本类型要 `.value`，reactive 包对象 ｜ 追问：ref 在模板里要 `.value` 吗（不用，自动解包）、解构 reactive 会怎样（失去响应式）｜ 深度：能说各自适用场景
- **computed vs watch**：computed 算派生值有缓存，watch 监听变化做副作用 ｜ 追问：缓存靠什么（依赖不变不重算）｜ 深度：能说什么时候用哪个
- **组件通信**：父传子 props，子传父 emit ｜ 追问：兄弟组件怎么通信（共同父级 / 状态管理）｜ 深度：能讲博客里 NoteCard 的 props
- **v-if vs v-show**：v-if 真销毁重建，v-show 只切 display ｜ 追问：频繁切换用哪个（v-show）、v-if 和 v-for 能一起用吗（不推荐）｜ 深度：能说性能取舍

### 网络 / 项目

- **输入 URL 到页面显示**：DNS 解析 → 建 TCP 连接 → 发 HTTP 请求 → 服务器返回 HTML → 浏览器解析渲染（DOM+CSSOM）→ 执行 JS ｜ 追问：哪里能优化（缓存/CDN/懒加载）｜ 深度：能把这几步说出来
- **项目 P1-P8**：见《面试包》。你要顺着每题往下追 **2 层**，她扛不住的地方就是要补的地方

## 4. 怎么识别"假性掌握"（背下来了但没懂）

危险信号：
- 只会背原话，你一换问法（"那如果…"）就卡
- 讲得出但**写不出**（手写题崩）
- 讲得出但**改不了**（让她改代码就懵）
- 隔天就忘

→ 遇到这些，**别往前赶进度**，回去重讲 + 重敲那一个点。宁可少讲几个讲透，也不要全覆盖但全夹生。

---

## 5. 模拟面试怎么组织（重点在 Day 13/14/15，有条件中间再加 1-2 次）

- **环境**：正式点，坐下、计时、你板着脸当陌生面试官
- **流程**（照真实一面）：自我介绍 → 项目深挖（顺一个点往死里问）→ 基础八股 → 现场手写（共享屏幕/白纸）→ 她反问
- **评分**：每题记"过 / 卡 / 崩"，崩的进弱项本
- **复盘**：结束当场说 3 个最致命的问题，第二天优先补
- **进阶**：找第二个"面试官"（朋友/网友）换风格问，避免她只适应你一个人

---

## 6. 心态 & 学历问题陪练

- 她会崩、会想放弃、可能哭——**正常**。全天高强度学一个月很累。多给正反馈（"这道题昨天不会，今天会了"）。
- **学历问题**（必被问）：陪她把《面试包》里那段练到平静、不卑不亢、**说完就停不过度解释**。她一慌就露怯。
- **别把你的焦虑传给她**。你急，但对她要稳。你的稳定就是她的底气。

---

## 7. 红线（别帮倒忙）

- ❌ 面试前夜帮她重写代码 / 大改口径——会和她平时表现对不上，露馅
- ❌ 替她答、替她敲、替她写简历到"不像她能说出来的"
- ❌ 无限扩大范围（"顺便把 TypeScript/Pinia/React 也学了"）——15 天守住现有范围就是胜利
- ✅ **repo 洗白**（清 `111` 垃圾 commit、教学注释去留、README 与代码对齐）这种"工程卫生"你可以代劳，
  但要在她开始讲项目**之前**搞定，并且让她知道改了什么、为什么——因为这本身也可能被面试官问到
