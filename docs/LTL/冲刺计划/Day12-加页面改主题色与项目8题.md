## ① 先读懂（上午 · 约 40min）——大白话

### 加一个新页面，要动三个地方（缺一不可）
这是前端最典型的"加个页面"活儿，面试官很爱问"你加个页面要改哪些地方"：
```
① 建页面文件      src/views/TestView.vue      ← 页面长什么样
② 加一条路由      src/router/index.js         ← 告诉路由"这个网址对应这个新页面"
③ 加一个导航项    src/components/NavBar.vue   ← 让导航栏出现能点进去的入口
```
- 只做①：页面文件有了，但没路由，输网址进不去。
- 只做①②：能靠网址进去，但导航栏没入口，用户点不到。
- **三处都做了**，才算完整加了一个页面。

> ⚠️ **顺序有坑**：加路由时，新路由要放在 `router/index.js` 里那条 **404 通配路由（`path: '/:pathMatch(.*)*'`）的前面**——通配路由是"兜底所有没匹配到的网址"，必须放最后，否则你的新页面会被它抢走、跳到 404。

## ② 动手做

### 改代码②（加一个新页面，上午后半）
1. **新建** `src/views/TestView.vue`，随便写点内容：
   ```vue
   <template>
     <div class="container">
       <h2>这是我的测试页</h2>
       <p>我学会了怎么加一个新页面：建文件 + 加路由 + 加导航项。</p>
     </div>
   </template>
   ```
2. **加路由**：打开 `src/router/index.js`，在 `routes` 数组里、**404 通配路由那条之前**，加一条（格式照抄现有路由）：
   ```js
   {
     path: '/test',
     name: 'Test',
     component: () => import('../views/TestView.vue'),
     meta: { title: '测试页' }
   },
   // ↓ 这条 404 通配路由必须留在最后，别动它的位置
   { path: '/:pathMatch(.*)*', name: 'NotFound', component: () => import('../views/NotFoundView.vue'), meta: { title: '页面不存在' } }
   ```
3. **加导航项**：打开 `src/components/NavBar.vue`，在 `navItems` 数组里加一项：
   ```js
   const navItems = [
     { path: '/', label: '首页' },
     { path: '/about', label: '关于我' },
     { path: '/notes', label: '学习笔记' },
     { path: '/projects', label: '项目展示' },
     { path: '/test', label: '测试' }          // ← 新加的入口
   ]
   ```
4. 保存，回浏览器：导航栏应该多出"测试"，点它能进到 `/test`，看到你的测试页内容。

### 改代码③（换全站主题色，下午）
1. 打开 `src/styles/global.css`，找到 `:root` 里的 `--color-primary`（现在是科技蓝 `#2563eb`）：
   ```css
   :root {
     --color-primary: #2563eb;   /* 改前：科技蓝 */
   }
   ```
2. 把它的颜色值改一下，比如改成绿色 `#16a34a`：
   ```css
   :root {
     --color-primary: #16a34a;   /* 改后：绿色 */
   }
   ```
3. 保存，回浏览器看——**整个网站的主色调（导航高亮、按钮、标签、标题……）一起变了**。
   - **只改了一处变量、全站生效**，这就是 CSS 变量（设计令牌）的威力：所有用到 `var(--color-primary)` 的地方都自动跟着变。

### 收尾：把②③撤销
玩完可以把这两个改动**改回原样**（删掉测试页 / 路由 / 导航项，主题色改回 `#2563eb`），保持本地和线上一致。

- ✅ **做对的标志**：能独立加一个新页面（三处都动到）并在导航里点进去；改 `--color-primary` 后全站主色一起变，能说清为什么。

## ⚠️ 今天最容易踩的坑

- **新路由加到了 404 通配路由后面** → 会被通配抢走、跳到 404；新路由必须放在通配路由**前面**。
- **加页面只改了路由、忘了加导航项** → 用户点不到入口，只能手输网址。
- **TestView.vue 忘了 `.container` 类** → 页面内容不居中、贴边，加上和其他页面统一。
- **改主题色改错变量** → 要改 `--color-primary`（主色），别改到 `--color-text`（正文色）。
- **改动忘了撤销** → 玩完记得改回原样，保持和线上一致（否则面试时线上/本地对不上）。
