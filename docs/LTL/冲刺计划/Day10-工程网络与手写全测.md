## ① 先读懂（上午 · 约 2h）——大白话

### 1. Git：代码的"存档 + 时光机"
改完存档一次（commit），出问题能回到之前任何一个存档点。最常用的三步：
```bash
git add .                    # ① 选中要存档的文件（. 表示全部改动）
git commit -m "加了笔记列表"   # ② 存档，并写清楚这次改了啥
git push                     # ③ 推到 GitHub 云端（别人/线上才看得到）
```
- **对应关系**：`add` = 挑东西放进箱子；`commit` = 封箱贴标签（写清楚这箱是啥）；`push` = 把箱子寄到云端仓库。
- ⚠️ 你在 **Windows PowerShell** 里敲命令，多条命令连起来用 `;` 不要用 `&&`（PowerShell 不认 `&&`）。

### 2. GitHub Actions：一条"自动流水线"
你把代码 `push` 到 main 分支，GitHub 就**自动**帮你打包 + 发布上线，不用你手动操作。
```
你 git push → GitHub 收到 → 触发 Actions 流水线：
   装依赖(npm ci) → 打包(npm run build) → 把 dist 发布到 GitHub Pages → 网站更新
```
- 打开 `.github/workflows/deploy.yml` **扫一眼**就行，**不用背**。知道"push 一下就自动上线"是它在背后干活即可。
- 这个 yml 文件里你会看到几个熟悉的命令：`npm ci`（装依赖）、`npm run build`（打包）——就是把你手动敲的命令写进脚本，让机器自动敲。

### 3. 从输入网址到页面显示（面试经典，务必能按顺序说）
大致**六步**：
```
① DNS 解析：把域名（如 huangwenhong.github.io）翻译成服务器的 IP 地址
② 建立 TCP 连接：浏览器和服务器"接上头"（HTTPS 还会多加一次 TLS 握手）
③ 发 HTTP 请求：浏览器向服务器要这个网页
④ 服务器返回 HTML：把网页的 HTML 文件发回来
⑤ 解析 + 渲染：浏览器解析 HTML 建 DOM 树、结合 CSS 建样式树，画出页面
⑥ 执行 JS：下载并执行 JavaScript，页面变得可交互（Vue 也在这一步接管）
```
- **记忆口诀**：「**翻地址 → 连线路 → 发请求 → 收 HTML → 画页面 → 跑 JS**」。能按顺序说出这六步就够了。

### 4. Vite 为什么快（题库 15，顺带搞懂）
- **开发时**：Vite 不像老工具那样"先把整个项目打包一遍再启动"，而是**按需编译**——你打开哪个页面，它才现编哪个文件，所以**启动飞快**。它底层用 Go 写的 esbuild 做依赖预构建，比 JS 写的工具快很多。
- **改代码时**：靠浏览器的原生 ES Module + 热更新（HMR），改一处只更新那一处，**不用整页刷新**。

## ③ 手写题：reduce 求和 / 求最大值（傍晚 · 约 40min）

> 对应《面试包》第五节 **第 10 题**，也是今天全测的最后一道。

**大白话**：`reduce` 是"把整个数组**揉成一个结果**"的工具。求和就是从 0 开始一个个累加；求最大值就是每次留下较大的那个。

**三步练**：看懂 `reduce((acc, cur) => ..., 初始值)` 里 `acc`（累计值）怎么滚动 → 照着敲 → **白纸默写**。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
// 求和：acc 从 0 开始，每轮加上当前项 cur
const sum = (arr) => arr.reduce((a, b) => a + b, 0)
// [1,2,3] → 0+1=1 → 1+2=3 → 3+3=6

// 求最大值：acc 每轮留下 a、b 里较大的那个（不写初始值，默认拿第一项当 acc）
const max = (arr) => arr.reduce((a, b) => (a > b ? a : b))
// [3,7,2] → max(3,7)=7 → max(7,2)=7
```

**reduce 怎么滚动（讲得出原理加分）**：`arr.reduce((acc, cur) => 新的acc, 初始值)`——每遍历一项，就把"上一轮的结果 acc"和"当前项 cur"算出一个新结果，当成下一轮的 acc，直到数组走完，返回最后那个 acc。

**面试怎么说（一句话）**：「`reduce` 把数组揉成一个值：求和初始值给 0、每轮 `a+b`；求最大不给初始值、每轮返回 `a>b?a:b`。」

## ⚠️ 今天最容易踩的坑

- **PowerShell 里用 `&&` 连命令** → Windows PowerShell 不认 `&&`，要用 `;`。
- **以为要手动上线** → 不用，`push` 到 main 后 GitHub Actions 自动部署。
- **手写全测忍不住翻答案** → 一定要闭卷计时，翻答案就测不出真实水平了。
- **reduce 求和忘了初始值 0** → `reduce((a,b)=>a+b)` 不给初始值时，会拿数组第一项当 acc（求和最好显式给 `0`，空数组也不报错）。
- **六步顺序记乱** → 用口诀"翻地址 → 连线路 → 发请求 → 收 HTML → 画页面 → 跑 JS"。
