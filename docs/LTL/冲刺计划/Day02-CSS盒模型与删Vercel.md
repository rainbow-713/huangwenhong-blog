## ① 先读懂（上午 · 约 2.5h）——用大白话把这几个词搞懂，读懂一个再往下看

### 1. CSS：管网页"长什么样"
颜色、大小、位置、间距，都是 CSS 管的。就是预备篇说的"装修"。
```css
/* 一条 CSS 规则 = 选择器 + 一堆样式 */
.card {               /* 选择器：给谁化妆 */
  color: #333;        /* 文字颜色 */
  padding: 16px;      /* 内边距 */
  border-radius: 8px; /* 圆角 */
}
```

### 2. 选择器：告诉浏览器"给谁化妆"
- `.card` → 所有"挂了 card 牌子"的元素（class，最常用）
- `#app` → 那个"id 叫 app"的唯一元素
- `h1` → 所有 `<h1>` 标签
> 项目里 `.card`、`.tag`、`.container` 都是 class 选择器，在 `global.css` 里能找到。

### 3. CSS 变量：一处定义，到处用（本项目重点用了）
```css
:root {
  --color-primary: #2563eb;   /* 定义一个变量：主色 */
}
.button { background: var(--color-primary); }  /* 用变量 */
.link   { color: var(--color-primary); }       /* 同一个变量 */
```
- 好处：**想换主题色，只改 `:root` 里那一处，整个网站用到它的地方全跟着变**（Day 12 你会亲手改一次，体会这个威力）。
- 在 `src/styles/global.css` 最上面的 `:root { ... }` 就能看到本项目定义的一堆变量。

### 4. 盒模型（重点，面试必问）
网页上**每个元素都是一个"盒子"**，从里到外四层：
```
margin    ← 最外层：这个盒子和"别的盒子"之间的距离（外边距）
 └ border   ← 边框（看得见的边线）
    └ padding  ← 内容和边框之间的空隙（内边距）
       └ content ← 最里面：盒子里装的东西（文字、图片）
```
- 记忆口诀：**内 padding、边 border、外 margin**，中间夹着 content。
- 面试常问"标准盒模型和 IE 盒模型区别" → 答案就是下面这条 `box-sizing`。

### 5. `box-sizing: border-box`
- 默认（`content-box`）：你设 `width: 100px`，只是 content 宽 100，加上 padding、border 后实际更宽，容易撑破排版。
- `border-box`：你设的 `width` **把 padding、border 一起算进去**，所见即所得，排版更好控制。
- `global.css` 里的 `* { box-sizing: border-box }` 就是给全站元素都设成这个。

## ③ 手写题：防抖（傍晚 · 约 40min）

> 对应《面试包》第五节 **第 1 题**。防抖是前端面试**最高频**的手写题，必须能默写。

**大白话**：**等你停止操作一段时间后，才执行**。比如搜索框，你打完字、停 300 毫秒它才去搜（不然你每敲一个字就搜一次，太浪费）。

**三步练**：
1. **看懂**下面代码的每一行（重点看 `timer` 和 `clearTimeout`）。
2. **照着敲 1 遍**。
3. **合上，白纸默写**——写不出再看、再默，直到能独立写出。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
function debounce(fn, delay = 300) {
  let timer = null                 // 定时器，靠"闭包"一直被记着（Day 9 会讲闭包）
  return function (...args) {      // 返回一个新函数，代替原来的 fn
    clearTimeout(timer)            // 关键：每次触发先把"上一个"定时器清掉，重新计时
    timer = setTimeout(() => {     // 停够 delay 毫秒后，才真正执行
      fn.apply(this, args)         // 执行原函数，把参数原样传进去
    }, delay)
  }
}
```

**为什么这样就是"防抖"**：你连续操作时，每次都 `clearTimeout` 把上一次的取消掉、重新计时；只有你**停下来超过 delay**，最后那次 `setTimeout` 才会真正执行。

**面试怎么说（一句话）**：「防抖是"停止触发后延迟执行"，核心是用一个定时器，每次触发先 `clearTimeout` 清掉旧的、再 `setTimeout` 重新计时，典型场景是搜索框输入。」

**（了解即可，先不用背）** 还有个"立即执行版"：第一次点马上执行、之后狂点不执行，用于防止按钮被连点重复提交。等基础版默熟了再研究。
