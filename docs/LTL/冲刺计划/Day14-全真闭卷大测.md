## ② 动手做

### 1. 手写题限时全测（上午，30 分钟）
- 10 道题，**30 分钟内闭卷全部写完**（严格计时，就当面试官坐对面盯着你）。
- 10 道是：防抖、节流、数组去重、深拷贝、扁平化、冒泡、字符串反转/回文、URL 参数解析、驼峰↔中划线、reduce 求和/最大。
- 写完立刻对答案，**错的、没写出的**用红笔标记，记下题号。
- 目标：**30 分钟内写完、且对 8 道以上**。

### 2. 八股抽问（下午）
- 让家人 / 朋友随便点题库里的题，或自己把 **19 题写在纸条上抽签**。
- 抽到就**脱口而出**（不许翻题库、不许想太久），练的是**反应速度**。
- 答不出的，标记题号，傍晚集中补。

### 3. 项目深挖自测（下午重点，全程录音）
自己当面试官，从"介绍一下你的博客项目"开始，**顺着往下追三层**，全程录音：
```
第 1 层：介绍一下你的博客项目？（P1）
   ↓ 追问
第 2 层：怎么部署的？（P3：push 到 main → GitHub Actions 自动打包发布到 GitHub Pages）
   ↓ 追问
第 3 层：为什么刷新会 404？你怎么解决的？（P4：SPA 只有一个 index.html；GitHub Pages 用 public/404.html 兜底）
```
- 录完**回放**，重点听：哪里卡壳、哪里讲不清、哪里"呃、然后"太多、逻辑有没有断。
- 把卡壳的地方重讲一遍，直到能**从"介绍"往下连续讲 5 分钟不卡壳**。

> ⚠️ 口径提醒：讲部署**只说 GitHub Pages**，别提 Vercel（Day 2 已删）。

## ⚠️ 今天最容易踩的坑

- **手写全测偷看答案 / 不计时** → 就失去模拟意义了，严格闭卷 + 计时。
- **项目深挖只答一层就停** → 面试官会一直追问，你要练到能扛住"为什么、怎么解决"连环三层。
- **录音嫌麻烦不录** → 一定要录！自己听回放才能发现卡壳和口头禅，光靠感觉发现不了。
- **测出问题就慌** → 别慌，今天暴露 = 明天能补 = 面试不栽。这正是大测的价值。
- **讲部署提了 Vercel** → 只说 GitHub Pages。

## 🆘 卡住了怎么办

1. 先自己回看《面试包》P1-P8、《面试题库-背诵版》、第五节手写题答案。
2. 还讲不清 / 写不出 → 记到「问题本」。
3. **晚上集中问哥哥**（先自己想过一遍再问）。
