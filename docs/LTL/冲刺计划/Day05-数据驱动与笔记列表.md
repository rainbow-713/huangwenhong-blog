## ① 先读懂（上午 · 约 2h）——大白话

### 1. 数据驱动视图（Vue 最核心的思想，今天必须亲眼见一次）
你**不用手动去改页面上的字**，你只要改数据，页面自己就跟着变（这叫"响应式"）。
```js
// notes.js 里每篇笔记长这样：
{ id: 1, title: '我的第一篇笔记', date: '2026-09-01', tags: ['Vue'], summary: '...' }
// 你只改 title 这个"数据"，保存 → 页面上的标题自动变
// 你一行"渲染代码"都没动 —— 这就是数据驱动
```

### 2. `==` vs `===`（面试必问）
```js
1 === '1'          // false（类型不同：数字 vs 字符串，严格相等要求"类型和值都一样"）
1 == '1'           // true （== 会偷偷把 '1' 转成数字 1 再比，这叫"隐式转换"）
null == undefined  // true （特例）
null === undefined // false
```
- **结论：永远优先用 `===`**，更安全、更明确，不会因为偷偷转类型出 bug。

### 3. notes 的数据结构
`notes.js` 里每一篇笔记是一个对象，有 `id / title / date / tags / summary` 几个字段。列表页就是把这个数组循环成一堆卡片。

## ③ 手写题：数组扁平化（傍晚 · 约 50min）

> 对应《面试包》第五节 **第 5 题**。把"套娃"数组拍平。

**大白话**：把一层套一层的数组拍平成一层，`[1,[2,[3]]]` 变成 `[1,2,3]`。

**三步练**：先记住 `flat(Infinity)` → 再看懂递归版 → 白纸默写。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
// 方法一：ES6 自带（最短，面试先说这个）
const flat = (arr) => arr.flat(Infinity)   // Infinity：不管套多少层，全拍平

// 方法二：递归 + reduce（讲得出原理加分）
function flatten(arr) {
  return arr.reduce((res, item) =>
    // 如果 item 还是数组，就递归把它拍平；否则直接接上
    res.concat(Array.isArray(item) ? flatten(item) : item), [])
}
```

**面试怎么说（一句话）**：「最简单用 `arr.flat(Infinity)`；要讲原理可以递归——遍历每一项，是数组就递归拍平再拼接，不是就直接接上。」
