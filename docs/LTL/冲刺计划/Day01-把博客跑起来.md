### 2. 认基础词（每个用自己的话说一句，说不出 = 没懂，回去重看）
下面每个词先给你一句大白话，再告诉你"在项目哪里能看到它"，你合上后自己复述一遍：

| 词 | 大白话 | 在项目哪里看得到 |
|---|---|---|
| 前端 | 把设计稿变成能点、能看的网页，你眼睛看到的界面都是前端的活 | 整个项目 |
| HTML | 网页的「骨架/结构」——哪块是标题、哪块是图 | `index.html` |
| CSS | 网页的「皮肤/装修」——颜色、大小、位置、间距 | `src/styles/global.css` |
| JS | 网页的「动作/逻辑」——点了有反应、数据会算 | `.vue` 文件里的 `<script setup>` |
| 框架 | 别人写好的「半成品工具箱」，不用从零搭 | 本项目用的是 Vue |
| Vue | 一个前端框架，核心本事是「数据变了，页面自动变」 | 所有 `.vue` 文件 |
| 组件 | 可复用的「乐高积木」，一个 `.vue` 文件就是一块积木 | `src/components/` |
| 路由 | 一张「网址 ↔ 页面」的对应表 | `src/router/index.js` |
| 终端 | 一个「打字指挥电脑」的黑框框，不用鼠标点 | VS Code 里按 `` Ctrl+` `` |
| npm | 装工具、跑命令的工具，`npm run dev` 就是它在跑 | `package.json` 里定义了能跑啥命令 |
| Git | 代码的「存档 + 时光机」 | 项目里的 `.git`（今天不碰） |

**HTML / CSS / JS 到底谁管啥？看这三行小例子就懂了**：

```html
<!-- HTML 管结构：这里有个标题、一个按钮 -->
<h1>黄雯宏</h1>
<button id="btn">点我</button>
```

```css
/* CSS 管样子：把标题变成蓝色、居中 */
h1 { color: #2563eb; text-align: center; }
```

```js
// JS 管动作：点按钮，弹一句话
document.getElementById('btn').onclick = () => alert('你好，我在学前端')
```

> 一句话记住：**HTML 是名词（有啥），CSS 是形容词（啥样），JS 是动词（能干啥）**。

## ③ 手写题：数组去重（傍晚 · 约 0.5h）

> 对应《面试包》第五节 **第 3 题**。这是你 15 天里写的第一道手写题，慢慢来。

**大白话**：数组就是一排数据 `[1,2,2,3]`，去重就是把重复的删掉，变成 `[1,2,3]`。

**三步练（务必按顺序）**：
1. **看懂**下面两种写法（先理解思路，别急着背）。
2. **照着敲 1 遍**（在 VS Code 或纸上）。
3. **合上，白纸上默写**——写不出再看、再默，直到能独立写出方法一。

**⚠️ 先自己在白纸默写，默不出再看下面的答案对——不要一上来就抄。**

```js
// 方法一：用 Set（最短，面试首选，先掌握这个）
// Set 是一种"不许重复"的盒子，把数组塞进去，重复的自动只留一个
// 前面的 ... 是"展开"，把 Set 再变回普通数组
const unique = (arr) => [...new Set(arr)]

// 方法二：filter + indexOf（能讲清原理，面试加分）
// filter 会遍历每个元素 v（i 是它的下标）
// arr.indexOf(v) 返回 v "第一次出现"的下标
// 如果"第一次出现的下标 === 当前下标"，说明是第一次见，留下；否则是重复的，丢掉
const unique2 = (arr) => arr.filter((v, i) => arr.indexOf(v) === i)

// 方法三：reduce + includes（"边累加边去重"，理解思路即可）
// res 是"已经收下的不重复元素"，遇到没收过的（!res.includes(v)）才加进去
const unique3 = (arr) => arr.reduce((res, v) => (res.includes(v) ? res : [...res, v]), [])
```

**面试怎么说（一句话）**：「最简单是用 `Set` 去重，`[...new Set(arr)]`；如果要讲原理，可以用 `filter` 配合 `indexOf`，保留第一次出现的元素。」
