## ① 先读懂（上午 · 约 2h）——大白话

### 1. 动态路由 `/notes/:id`：一个 `:id` 匹配一堆网址
那个 `:id` 是个"占位参数"。一条路由就能同时匹配 `/notes/1`、`/notes/2`、`/notes/3`……不用给每篇笔记都写一条路由。
```js
{ path: '/notes/:id', component: () => import('../views/NoteDetailView.vue') }
// /notes/1、/notes/2、/notes/3 都走这一条
```

### 2. `useRoute()`：把网址里的参数抠出来
```js
import { useRoute } from 'vue-router'
const route = useRoute()
route.params.id   // 就是那个 :id
// ⚠️ 注意：抠出来是字符串 '1'，不是数字 1，比较时要留意
```

### 3. 为什么用 computed 不用 onMounted（面试可能问，重点）
你从 `/notes/1` 点到 `/notes/2` 时，Vue 觉得"还是同一个详情页"，**不会把组件销毁重建**，只是换了参数。
- 如果只在 `onMounted`（组件第一次挂载时）查一次，参数变了它**不会重查**，页面还停在上一篇。
- 用 `computed` 则**参数一变就自动重新查**对应笔记。
```js
import { computed } from 'vue'
import { getNoteById } from '../data/notes'

const note = computed(() => getNoteById(route.params.id))  // 参数变，自动重查
```

### 4. 组件通信：props（父传子）+ emit（子传父）
- 父组件给子组件传数据用 `props`（Day 3 学过）。
- 子组件想通知父组件用 `emit`（抛一个事件上去）。
```vue
<!-- 子组件里：点按钮，通知父组件 -->
<button @click="$emit('delete', id)">删除</button>
```

## ③ 手写题：字符串反转 / 判断回文（傍晚 · 约 40min）

> 对应《面试包》第五节 **第 7 题**。简单但高频，必须秒写。

**大白话**：反转就是把 `'abc'` 变成 `'cba'`；回文就是正着读反着读都一样（比如 `'level'`、`'上海自来水来自海上'`）。

**三步练**：记住组合拳 → 照着敲 → 白纸默写（反转 + 回文都要会）。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
// 反转：拆成数组 → 反转数组 → 拼回字符串
const reverse = (str) => str.split('').reverse().join('')

// 判断回文：反转后和原来相等，就是回文
const isPalindrome = (str) => str === reverse(str)
```

**面试怎么说（一句话）**：「反转用 `split('').reverse().join('')`；回文就是判断"反转后 === 原字符串"。」

## ⚠️ 今天最容易踩的坑

- **`route.params.id` 当成数字** → 它是字符串 `'1'`，如果和数字 `1` 用 `===` 比会 false。
- **用 onMounted 查笔记** → 切换 `/notes/1 → /notes/2` 时页面不更新，这就是为什么要用 computed。
- **忘了 `v-if="note"` 兜底** → 万一 id 找不到对应笔记，页面会报错/白屏。
- **emit 事件名大小写** → 模板里建议用短横线命名（如 `@my-event`）。
