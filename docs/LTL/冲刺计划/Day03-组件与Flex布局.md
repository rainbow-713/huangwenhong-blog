## ① 先读懂（上午 · 约 2h）——大白话

### 1. 组件：可复用的"乐高积木"
一个 `.vue` 文件就是一块积木。`NoteCard.vue` 就是一张"笔记卡片"积木，哪里要显示笔记，就把这块积木搬过去用，不用每次重写。
```vue
<!-- NoteCard.vue：一张"笔记卡片"组件 -->
<template>
  <div class="card">{{ note.title }}</div>   <!-- 显示喂进来的笔记标题 -->
</template>

<script setup>
defineProps({ note: Object })   // 声明：我会接收一个叫 note 的数据
</script>
```
> 一个 `.vue` 文件通常三块：`<template>`（结构，长啥样）、`<script setup>`（逻辑，处理数据）、`<style>`（样式）。

### 2. props（父传子）：上级给下级"喂数据"
卡片自己不知道要显示啥，是**笔记列表页**（父组件）把每一条笔记"喂"给它（子组件）。这个"喂数据"的通道就叫 props。
```vue
<!-- 父组件（列表页 NotesView）把每条 note 喂给子组件（卡片 NoteCard） -->
<NoteCard v-for="note in notes" :key="note.id" :note="note" />
```

### 3. v-for / :key：循环 + 身份证
- `v-for="note in notes"`：把 `notes` 数组循环，一条数据渲染成一张卡片。
- `:key="note.id"`：给每个元素发一张"身份证"，方便 Vue 追踪谁是谁（增删改时不认错人）。**key 要唯一、稳定，别用下标凑合。**

### 4. Flex 布局（今天的重点，面试最高频）
一种排版方式。记住两个属性就够了：
- `justify-content` 管**主轴**（默认水平方向，左右）
- `align-items` 管**交叉轴**（默认垂直方向，上下）
- **两个都设成 `center`，东西就到正中间**——这是面试考烂了的题，必须能当场写出来。
```css
.box {
  display: flex;            /* 开启 Flex */
  justify-content: center;  /* 主轴（水平）居中 */
  align-items: center;      /* 交叉轴（垂直）居中 */
  height: 100vh;            /* 要有高度，垂直居中才看得出来 */
}
```

## ③ 手写题：节流（傍晚 · 约 40min）

> 对应《面试包》第五节 **第 2 题**。常和防抖一起考，重点记"它俩的区别"。

**大白话**：不管触发多频繁，**每隔固定时间最多执行一次**。比如页面滚动，300 毫秒最多算一次。

**和防抖的区别（面试爱问，务必记牢）**：
- **防抖**：停下来才做（等你不操作了，延迟执行最后一次）——像电梯关门，有人进来就重新等。
- **节流**：按点做（不管你怎么触发，我固定每隔一段时间做一次）——像水龙头，固定频率滴水。

**三步练**：看懂每一行 → 照着敲 1 遍 → **合上、白纸默写**。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
function throttle(fn, interval = 300) {
  let last = 0                     // 上次执行的时间戳，靠"闭包"一直记着
  return function (...args) {
    const now = Date.now()         // 现在的时间戳
    if (now - last >= interval) {  // 距离上次执行，够久了吗？
      last = now                   // 够久 → 更新"上次执行时间"
      fn.apply(this, args)         // 真正执行
    }
    // 不够久 → 什么都不做（这次触发被"节流"掉了）
  }
}
```

**面试怎么说（一句话）**：「节流是"固定频率执行"，用一个 `last` 记录上次执行时间，只有距离上次超过 interval 才执行，典型场景是滚动、拖拽。」

## ⚠️ 今天最容易踩的坑

- **垂直居中不生效** → 多半是父容器**没有高度**（`height`）。Flex 垂直居中要有高度才看得出来。
- **`:key` 用数组下标** → 能跑但不规范，增删数据时可能出错。用数据里唯一的 `id`。
- **主轴/交叉轴搞反** → 记住默认 `flex-direction: row`（横排）时，`justify-content` 管左右、`align-items` 管上下。
- **一卡就让 AI 写 NoteCard** → 违反纪律。先自己敲，敲不出瞄一眼原文件再关掉重敲。
