## ① 先读懂（上午 · 模拟前 5 分钟）

今天模拟要**越正式越好**：穿上正常衣服、坐直、手机录视频，就当屏幕对面坐着真面试官。
- 目的：**提前适应紧张感**。真面试会紧张，模拟时先紧张几轮，上场就没那么慌了。
- 别追求完美：模拟就是用来暴露问题的，发现问题、改掉，就是赚。

## ② 动手做

### 1. 完整模拟一轮（上午，手机录视频）
一口气走完一整轮，全程录下来：
```
① 自我介绍（30 秒）
② 介绍项目（博客 P1，再准备好被追部署 P3、404 P4）
③ 基础八股抽问（让家人点题，或自己抽题库 1-19）
④ 现场手写 2 道（从 10 道里随机抽，白纸写）
⑤ 最后你反问面试官
```
- **反问环节**准备 2-3 个问题（体现你有意愿、有思考）：
  - "团队主要用什么技术栈？"
  - "实习生一般做什么样的活？有没有人带？"
  - "如果我有幸加入，您希望我先补哪方面？"
- 录完**回放**，记下**最致命的 3 个问题**（比如：某题卡壳、口头禅太多、项目讲得乱），逐个改，再模拟一遍。

### 2. 简历定稿（下午）
- 照《面试包》**第一节**，把**项目栏**和**技能栏**抄下来，整理成你的简历。
- **一定要填上真实的线上网址**（GitHub Pages 地址），并且**自己先点开确认能正常访问**——这是你和大部分竞争者拉开差距的地方：别人简历写"熟悉 Vue"，你是"点开就能看"。
- 技能栏口径：HTML / CSS / JavaScript 基础扎实 → Vue3 会用 → Git / GitHub 会用 → 会部署静态网站。**不要写"精通"任何东西。**

### 3. 开始投递（傍晚）
- 照《面试包》**第七节**的目标公司池子（外包实习、小工作室 / 建站公司、Boss 直聘"学历不限"前端实习岗、小城市网页维护岗）和打招呼话术开始投。
- **今天先投出一批，别追求完美，先投起来**——投递是概率游戏，投得越早、越多，机会越早来。
- 打招呼话术参考第七节：说清"学前端的、做了个已上线的博客、想找实习、工资要求不高、想在实际项目里成长"，附上简历。

## ⚠️ 今天最容易踩的坑

- **模拟不录视频** → 一定要录，回放才能看出真问题（表情、口头禅、卡壳）。
- **简历网址填错 / 没验证** → 填完**自己先点开**，确认线上能正常打开（面试官一定会点）。
- **简历写"精通"** → 实习生写"精通"很危险，容易被追问到崩；写"基础扎实 / 会用"。
- **投递追求完美、迟迟不投** → 先投起来！边投边改，别等"完全准备好"（永远没有那天）。
- **口径又提 Vercel** → 部署只说 GitHub Pages。

## 🆘 卡住了怎么办

1. 先自己回看《面试包》第一、七节。
2. 简历 / 投递拿不准 → 记到「问题本」。
3. **晚上集中问哥哥**（先自己想过一遍再问）。
