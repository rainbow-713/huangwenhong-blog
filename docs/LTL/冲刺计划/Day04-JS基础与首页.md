## ① 先读懂（上午 · 约 2.5h，今天是重点，慢慢看）——大白话

### 1. 变量：给数据起个名字
像贴了标签的盒子。`let count = 0` 就是拿个盒子叫 `count`，里面装着 `0`。

### 2. let / const / var（面试必问区别）
```js
const name = '黄雯宏'  // 常量，赋值后不能再改（能用就优先用它）
let age = 20           // 可以改
age = 21               // ✅ 合法
// name = '别人'       // ❌ 报错，const 不能改
```
- `const`：优先用，防止手滑改错。
- `let`：确实要改的时候用。
- `var`：老写法，有作用域的坑，**别用**。

### 3. 箭头函数：写函数的简写
```js
// 普通函数
function add(a, b) { return a + b }
// 箭头函数（简写，return 都能省）
const add = (a, b) => a + b
// 只有一个参数，括号也能省
const double = n => n * 2
```
> 它还有个特点：**没有自己的 `this`**（这句先记住，面试可能问，深挖等以后）。

### 4. 插值 `{{ }}`：把数据显示到页面上
```vue
<h1>{{ profile.name }}</h1>   <!-- 把 profile.name 显示出来 -->
<span v-for="skill in profile.skills" :key="skill">{{ skill }}</span>
```

### 5. computed（计算属性）：算出一个新数据，还有缓存
```js
// 项目首页：从所有笔记里取最新 3 篇
const latestNotes = computed(() => notes.slice(0, 3))
// notes 没变时，latestNotes 不会重新算 —— 这就是"缓存"，比每次手动算更省
```
- 大白话：根据别的数据"算"出一个新数据；依赖的数据没变，它就不重新算。

## ③ 手写题：深拷贝（傍晚 · 约 50min）

> 对应《面试包》第五节 **第 4 题**。深浅拷贝是高频考点，**能讲清递归版就赢过大部分实习生**。

**大白话**：
- **浅拷贝**：只复制最外面一层，里面几层还和原来**共用**（改一个，另一个也跟着变）。
- **深拷贝**：里里外外全复制一份**独立的**，改新的不影响旧的。

**三步练**：先记住 JSON 快方法 → 重点练手写递归版 → 白纸默写递归版。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
// 方法一：JSON 大法（最短，但有局限，面试要能说出局限）
// 局限：函数、undefined、Date、正则 会丢失或出错
const deep1 = (obj) => JSON.parse(JSON.stringify(obj))

// 方法二：手写递归（重点掌握，能讲清就赢了）
function deepClone(obj) {
  // 递归出口：null 或不是对象（数字/字符串等），直接返回，不用再拷
  if (obj === null || typeof obj !== 'object') return obj
  // 判断是数组还是对象，准备一个同类型的空容器
  const result = Array.isArray(obj) ? [] : {}
  // 遍历每个键，对每个值再"递归"深拷贝
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {       // 只拷自己的属性，不拷原型链上的
      result[key] = deepClone(obj[key])  // 递归：里层也拷一份独立的
    }
  }
  return result
}
```

**面试怎么说（一句话）**：「浅拷贝只复制第一层、里层还是引用；深拷贝要递归把每层都复制成独立的。快速可以用 `JSON.parse(JSON.stringify())`，但它处理不了函数、Date 等，所以我会手写递归版。」
