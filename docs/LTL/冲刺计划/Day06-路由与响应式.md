## ① 先读懂（上午 · 约 2.5h）——大白话

### 1. 路由：一张"网址 ↔ 页面"的对应表
你在地址栏敲 `/about`，路由就翻这张表，找到"关于我"这个页面搬给你看；敲 `/notes` 就搬笔记列表。
```js
// router/index.js 的路由表（简化示意）
const routes = [
  { path: '/',        component: () => import('../views/HomeView.vue') },
  { path: '/about',   component: () => import('../views/AboutView.vue') },
  { path: '/notes',   component: () => import('../views/NotesView.vue') },
  { path: '/notes/:id', component: () => import('../views/NoteDetailView.vue') },
]
```

### 2. history 模式：让网址长得干净
- `createWebHistory` 就是 history 模式，网址是 `/about`，没有那个难看的 `#`。
- **代价**：直接刷新一个深层网址（比如 `/notes/1`），服务器会找不到文件而报 404——这个坑 **Day 11** 细讲怎么解决。

### 3. 懒加载 `() => import('...')`：用到哪个页面才下载哪个
不是一上来把所有页面代码全下载，而是访问哪个页面才去下载它，**首屏打开更快**。上面路由表里的 `() => import(...)` 就是懒加载。

### 4. Vue 响应式（面试常问，能说这一句就够）
Vue3 用 **Proxy**（代理）把数据"包"起来偷偷盯着，你一改数据，它立刻通知页面重新渲染。
> **标准说法**：「Vue3 用 Proxy 劫持数据，数据变化时自动收集到的依赖会被通知，从而更新视图。」

### 5. ref / reactive：让数据变"响应式"的两个工具
```js
import { ref, reactive } from 'vue'

const count = ref(0)          // ref 装单个值（数字/字符串）
count.value++                 // JS 里改要用 .value；模板里自动解包，不用 .value

const user = reactive({ name: '黄雯宏' })  // reactive 只装对象
user.name = '改一下'          // 直接改，不用 .value
```
- 一句话区别：**ref 什么都能装、JS 里要 `.value`；reactive 只装对象、不用 `.value`。**

## ③ 手写题：冒泡排序（傍晚 · 约 50min）

> 对应《面试包》第五节 **第 6 题**。最经典的排序题，必须会。

**大白话**：让一排数从小到大排队。相邻两个比，大的往后挪（像气泡往上冒），一轮下来最大的那个就被"冒"到最后。重复几轮就全排好了。

**三步练**：看懂双层 for 循环 → 照着敲 1 遍 → **合上、白纸默写**。

**⚠️ 先自己白纸默写，默不出再看答案对——不要一上来就抄。**

```js
function bubble(arr) {
  for (let i = 0; i < arr.length - 1; i++) {          // 外层：走多少轮（n-1 轮就够）
    for (let j = 0; j < arr.length - 1 - i; j++) {    // 内层：两两比较；-i 因为每轮末尾已排好，不用再比
      if (arr[j] > arr[j + 1]) {                      // 前面比后面大，就交换它俩
        ;[arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]  // 解构交换（不用临时变量）
      }
    }
  }
  return arr
}
```

**面试怎么说（一句话）**：「冒泡是双层循环，每轮把相邻两个比较、大的往后换，一轮下来最大的沉到最后；`n-1` 轮排完，时间复杂度 O(n²)。」
