## 三、几条要记住的口径

> - 网站现在是 **4 个页面**：首页、关于我、学习笔记、项目展示（一切以线上实际为准）。
> - 部署**只用 GitHub Pages**（Vercel 已在 Day 2 亲手删掉，面试别提"部署了两个平台"）。
> - 早期《双项目面试题》《书店项目面试口径》在隔壁 `docs/interview-prep/`，为**留档、不用背**，一切以《面试包》为准。

## 四、模拟面试复盘档案（使用方式）

- 每次模拟 / 真实面试结束后，新建一个 Markdown 文件，命名格式：`YYYY-MM-DD-主题.md`
- 内容包含：面试题目、我的回答、参考答案要点、改进建议

```markdown
# 面试记录：XXXX-XX-XX（主题）

## 总体评价
（本次表现概述、薄弱点）

## 题目记录
### 1. 题目内容
- 我的回答：
- 参考答案要点：
- 改进建议：

## 下次面试前需要补强的点
- [ ] ...
```
