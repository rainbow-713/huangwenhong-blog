# 开始必读 · 学习纪律（先读这个，再读别的）

> 开始 15 天冲刺前，先花 10 分钟读完这一页。这里讲的**不是知识，是规矩**——
> 守规矩，这 15 天才有用；不守，做再多也是白费。读完再去看《预备篇》和《15 天每日任务清单》。

---

## 一、最重要的一条：手敲，绝不让 AI 替你写

先把话说透，你就明白为什么这条这么重要：

- 这个博客当初是**用 AI 生成的**，代码不是你自己一行行敲出来的。结果是——项目很漂亮，但**你看不懂、讲不出、也写不来**。
- 面试官**不看项目漂不漂亮**。他会让你：**当场手写代码、当场改代码、顺着项目往深里一层层问**。
- 这些 AI 都帮不了你。他盯着你的时候，你得**自己写、自己讲**。写不出、讲不清，当场就露馅。

所以这 15 天只有一条铁律：

> **所有代码，你自己一个字一个字敲进电脑。不许复制粘贴，不许让 AI 生成好给你。**
> 敲错了、敲慢了都没关系——**手敲过一遍，才是你的。**

## 二、那 AI 和"问人"到底能不能用？能，但只能这样用

不是完全不让你用，是**用对方法**：

| ✅ 可以（把 AI 当老师） | ❌ 不可以（把 AI 当枪手） |
|---|---|
| "这段代码**为什么**这么写？" | "帮我写一个防抖函数" |
| "computed 和 watch **有什么区别**？" | "这道题答案直接给我" |
| "我这样理解对吗：……？" | "帮我把这个页面生成出来" |
| "这个报错**是什么意思**？" | "帮我把代码改对" |

**遇到不懂的，正确顺序是**：
1. 先自己看文档、看代码，**想 30 秒**
2. 还想不通 → 再问，而且**问"为什么 / 是什么意思"**，不是"帮我做"
3. 问懂了 → **自己把它敲出来 / 讲出来**，才算真的会

> 一句话记住：**AI 是你的老师，不是你的枪手。让它教你，别让它替你考。**
> 你越依赖它替你写，面试时你越写不出——因为面试没有 AI。

## 三、你电脑已经装好了，怎么把项目打开跑起来

环境哥哥已经帮你弄好了，**不用再装任何东西**，只要会"打开 + 跑起来"：

1. 打开 **VS Code**，菜单 `文件 → 打开文件夹`，选中博客项目文件夹
2. 打开终端：按 `` Ctrl + ` ``（Ctrl 加左上角反引号键），或菜单 `终端 → 新建终端`
3. 在终端敲这行，回车：
   ```
   npm run dev
   ```
4. 终端会显示一个网址（类似 `http://localhost:5173`），**按住 Ctrl 点它**，或自己开浏览器输入这个网址 → 博客就出现了 🎉
5. 想关掉：回终端按 `Ctrl + C`。明天再打开，重复第 1-4 步即可

> 万一 `npm run dev` 报错说找不到依赖，才需要敲一次 `npm install` 再重试。正常情况电脑装好了就不用。

**基础词**（什么是前端 / 框架 / Vue / 组件 / 路由 / 终端）——看《预备篇》第一部分，用大白话讲得很清楚。

## 四、每天雷打不动的三件事

1. **手敲重建**：看懂一个文件 → **关掉它** → 自己重敲一个一模一样的 → 敲不出再瞄一眼 → 再关掉重敲
2. **白纸手写题**：当天的手写题，**用笔在纸上写**，不是敲键盘（面试会让你手写/共享屏幕）
3. **写今日复盘**：一句"我今天真正搞懂了什么"，用自己的话，**不许抄**

## 五、给你的一句话

你不是笨，只是之前**没真正动过手**。这 15 天，只要你每天**老实手敲、老实背、不懂就问原理**，
到 Day 15 你会发现：这个项目你能看懂了、能讲清了、能自己改了——**那时候你就真的有底气去找实习了。**

慢慢来，别急，也别偷懒让 AI 替你走。**你自己走一遍，才算数。** 加油。
