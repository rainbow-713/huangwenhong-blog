## 模拟面试复盘档案（使用方式）
- 每次模拟面试结束后，新建一个 Markdown 文件，命名格式：`YYYY-MM-DD-主题.md`
- 文件内容包含：面试题目、我的回答、参考答案要点、改进建议

## 记录模板
```markdown
# 模拟面试记录：XXXX-XX-XX（主题）

## 总体评价
（本次表现概述、薄弱点）

## 题目记录
### 1. 题目内容
- 我的回答：
- 参考答案要点：
- 改进建议：

## 下次面试前需要补强的点
- [ ] ...
```
