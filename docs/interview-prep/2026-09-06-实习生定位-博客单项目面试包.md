## 三、博客项目面试题（8 题，全部 30 秒口径）

### P1 介绍一下你的博客

> "一个求职用的作品集网站，相当于在线简历加学习记录。五个页面：首页、关于我、学习笔记、项目展示、面试准备。技术上是很常规的 Vue3 + Vite，页面切换用路由，内容写在本地 JS 文件里，纯静态不需要后端。已经上线了，GitHub Pages 和 Vercel 各放了一份。"

**追问"为什么不用后端"**：
> "内容就是我自己写的笔记和介绍，没有用户交互和动态数据，纯静态最合适——免费托管、加载快、不用维护服务器。"

### P2 为什么做这个博客？

> "两个目的：一是把简历内容做成能点开的网页，面试时直接发链接，比 PDF 有说服力；二是把学习笔记和面试题放进去，边学边攒，平时也是复习工具。"

### P3 博客怎么上线的？（王牌题，40 秒）

> "代码托管在 Gitee 和 GitHub 上。GitHub 那边配了自动部署：推代码到 main 分支，GitHub Actions 就自动打包发布到 Pages，全程不用手动操作。另外在 Vercel 也部署了一份当备用地址。中间主要踩了两个坑：一个是国内访问 GitHub 很慢，配了 hosts 加速解决的；另一个是单页应用刷新会 404，这个是部署静态单页应用的经典问题。"

**结尾是故意的钩子**——面试官顺着问 404，正好你有 P4 现成答案。

**被追问（一句话就停）**：
- "npm ci 和 npm install 区别？" → "npm ci 严格按 lock 文件装，结果可复现，CI 环境推荐它。"
- "hosts 加速什么原理？" → "手动把 GitHub 域名指定到响应快的 IP，绕过 DNS 解析慢。"

### P4 刷新 404 是怎么回事？

> "单页应用其实只有一个 index.html，地址像 /notes/1 只是前端在管理。直接刷新时浏览器会去服务器找这个文件，找不到就 404。解决就是让服务器把请求都指回 index.html：Vercel 支持在配置里写重写规则；GitHub Pages 不支持，我用了个社区通用的办法——自定义一个 404 页面，记住原地址跳回首页再还原给前端路由。"

### P5 博客的数据怎么存的？

> "写在项目里的 JS 文件中，一个数组导出，组件 import 进来用。加一篇笔记就往数组里加一条，重新部署就更新了。"

**追问"为什么不用数据库"**：
> "纯展示内容，写死在 JS 文件里对静态站最简单。以后真要频繁更新再考虑接接口。"

### P6 为什么手写 CSS 不用组件库？

> "学习性质的项目，想练布局基本功。主题色用 CSS 变量统一管理，改一处全站生效。"

### P7 遇到的最大困难是什么？

> "部署上线的过程。以前只会写页面，第一次要把网站真的放到网上，遇到一堆环境问题——Git 推送认证、国内访问 GitHub 超时、部署完刷新 404，都是一个个查资料解决的。解决了这些问题后，我对'一个网站是怎么跑起来的'有了完整认识。"

### P8 你还会什么 / 在学什么？

> "现在在系统过 JS 基础——闭包、原型链、事件循环这些，博客的学习笔记里都有记录。下一步想把 Vue 的组件通信和常见手写题练熟。"

## 五、手写题 10 道（核心资产，每天写一遍）

### 1. 防抖（等停止输入再执行）
```js
function debounce(fn, delay = 300) {
  let timer = null
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}
```
**一句话**：搜索框，停止输入 300ms 后才查询。

### 2. 节流（固定频率执行）
```js
function throttle(fn, interval = 300) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn.apply(this, args)
    }
  }
}
```
**一句话**：滚动事件，300ms 最多执行一次。

### 3. 数组去重
```js
// 方法一：Set（最短）
const unique = (arr) => [...new Set(arr)]
// 方法二：filter + indexOf
const unique2 = (arr) => arr.filter((v, i) => arr.indexOf(v) === i)
```

### 4. 深拷贝
```js
// 快方法（有局限：函数、undefined、日期会出问题）
const deep1 = (obj) => JSON.parse(JSON.stringify(obj))
// 手写递归（能讲清这个就赢了大部分实习生）
function deepClone(obj) {
  if (obj === null || typeof obj !== 'object') return obj
  const result = Array.isArray(obj) ? [] : {}
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      result[key] = deepClone(obj[key])
    }
  }
  return result
}
```

### 5. 数组扁平化
```js
// 方法一：ES6 自带
const flat = (arr) => arr.flat(Infinity)
// 方法二：递归
function flatten(arr) {
  return arr.reduce((res, item) =>
    res.concat(Array.isArray(item) ? flatten(item) : item), [])
}
```

### 6. 冒泡排序
```js
function bubble(arr) {
  for (let i = 0; i < arr.length - 1; i++) {
    for (let j = 0; j < arr.length - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        ;[arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]
      }
    }
  }
  return arr
}
```
**一句话**：相邻两个比，大的往后冒，一轮冒出一个最大值。

### 7. 字符串反转 / 回文判断
```js
const reverse = (str) => str.split('').reverse().join('')
const isPalindrome = (str) => str === reverse(str)
```

### 8. URL 参数解析
```js
// '?a=1&b=2' → { a: '1', b: '2' }
function parse(url) {
  const obj = {}
  url.slice(url.indexOf('?') + 1).split('&').forEach(pair => {
    if (!pair) return
    const [k, v] = pair.split('=')
    obj[k] = v
  })
  return obj
}
```

### 9. 驼峰 ↔ 中划线互转
```js
// 'get-element' → 'getElement'
const camelize = (s) => s.replace(/-(\w)/g, (_, c) => c.toUpperCase())
// 'getElement' → 'get-element'
const dashify = (s) => s.replace(/[A-Z]/g, (c) => '-' + c.toLowerCase())
```

### 10. reduce 求和 / 求最大值
```js
const sum = (arr) => arr.reduce((a, b) => a + b, 0)
const max = (arr) => arr.reduce((a, b) => (a > b ? a : b))
```

**练习方法**：每天白纸手写一遍 10 道，一周后闭卷能在 30 分钟内写完，就算过关。
