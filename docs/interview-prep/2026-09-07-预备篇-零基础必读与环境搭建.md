## 第一部分：先把这些词搞懂（大白话 + 打比方）

### 1. 什么是"前端"？
一个网站/APP，你**眼睛看到的、手能点的**那部分就是前端——按钮、图片、文字、布局、动画。
你看不到的（存在服务器上的数据、账号密码校验）叫**后端**。
> 一句话：前端 = 网站的"脸面"和"交互"。你要学的、要找的工作就是这个。

### 2. HTML / CSS / JavaScript 是什么？（前端三大基础）
用"盖房子"打比方：

| 名字 | 好比 | 作用 |
|---|---|---|
| **HTML** | 毛坯房 / 骨架 | 决定页面上**有什么**：一个标题、一段文字、一张图、一个按钮 |
| **CSS** | 装修 | 决定**长什么样**：颜色、大小、位置、间距、好不好看 |
| **JavaScript（JS）** | 水电和开关 | 决定**能干什么**：点按钮弹东西、输入内容做反应、向后端要数据 |

> 你的博客这三样都用了。它们是所有前端的地基。

### 3. 什么是"框架"？（哥哥说你可能不懂这个词）
框架 = **别人提前搭好的一套工具箱 + 规矩**，让你不用什么都从零造。
打比方：你要做一桌菜，"框架"就像一套配好的半成品 + 趁手的厨具，你不用自己种菜、自己打铁。
> 好处：写得更快、更规范、别人容易看懂。代价：得先学它的规矩。
> **Vue 就是一个前端框架**（另一个很有名的叫 React）。你的博客用的就是 Vue。

### 4. 什么是 Vue？
Vue 是**帮你更快写页面的前端框架**。核心思想一句话：
> **你只管改数据，页面自动跟着变**——不用手动去操作页面。
比如购物车数字从 1 改成 2，你只改那个数字，页面上显示的"1"就自动变成"2"。这就是 Vue 最神奇的地方，叫**响应式**。

### 5. 什么是"组件"？
组件 = **乐高积木**。把页面拆成一块块能重复用的小零件。
你的博客里：顶部导航栏是一个组件、一张笔记卡片是一个组件、页脚是一个组件。
> 好处：一块积木做好了到处能用，改一处、所有用到它的地方都跟着变。

### 6. 什么是"路由"？
路由 = **网址和页面的对应表**。
地址栏输入 `/about` 显示"关于我"，输入 `/notes` 显示"学习笔记"——这个"哪个网址对应哪个页面"的规则就是路由。

### 7. 什么是"终端 / 命令行"？
一个**黑框框**，你在里面打字，电脑照做。别怕，程序员天天用。
这一个月你常用的命令就三四个，我会一个个教你敲。

### 8. 什么是 Node.js 和 npm？
- **Node.js**：让 JavaScript 能在"电脑上"（不只是浏览器里）跑起来的程序，装项目工具需要它。
- **npm**：跟着 Node.js 一起装的"**应用商店**"，用来下载项目需要的工具包。
> 你会用到的命令：`npm install`（下载项目要的工具）、`npm run dev`（把网站在本地打开预览）。

### 9. 什么是 VS Code？
程序员写代码的软件，相当于"程序员的 Word"。免费、好用。你会在它里面看代码、敲代码、开终端。

### 10. 什么是 Git / GitHub / Gitee？
- **Git**：代码的"**存档 + 时光机**"，每做一步存个档，改坏了能退回。
- **GitHub / Gitee**：放代码的**网站**（GitHub 国外、Gitee 码云国内）。你的博客代码就放在上面。

### 11. 什么是"部署 / 上线"？
把做好的网站**放到网上的一台电脑（服务器）上**，让任何人输入网址都能打开。
你的博客**已经上线了**——这就是它比很多简历强的地方。

## 第二部分：把博客在你电脑上打开（一步步来）

> **如果你电脑已经装好了 Node.js 和 VS Code（哥哥已帮你弄好），下面这些"安装"步骤全部跳过**，
> 直接看《开始必读-学习纪律》第三节"怎么把项目打开跑起来"即可。从头安装是给还没装的人备用的。
>
> 目标：今天结束前，你能在自己电脑的浏览器里看到博客跑起来。做成这一步，第一道坎就过了。
> 遇到看不懂的报错**别慌，截图或抄下来**，晚上问哥哥。

### 步骤 1：装 Node.js
1. 浏览器打开官网：`https://nodejs.org`
2. 下载 **LTS 版本**（LTS = 长期稳定版，页面会标，选它准没错）
3. 双击安装包，一路"下一步 / Next"，默认选项即可，直到装完
4. 先不用管验证，等下用终端敲命令验证

### 步骤 2：装 VS Code
1. 浏览器打开：`https://code.visualstudio.com`
2. 下载 Windows 版，双击安装，一路"下一步"
3. （可选）装好后在里面搜 `Chinese` 插件，装个中文语言包，界面变中文更好懂

### 步骤 3：用 VS Code 打开博客项目
1. 打开 VS Code
2. 菜单 `文件 → 打开文件夹`，选中博客项目文件夹（路径问哥哥，例如 `F:\Project\huangwenhong-blog`）
3. 左边出现一堆文件和文件夹 = 打开成功

### 步骤 4：打开终端
- 快捷键：按 `` Ctrl + ` ``（Ctrl 加左上角那个反引号键，在数字 1 左边、Esc 下面）
- 或菜单：`终端 → 新建终端`
- 下方弹出一个黑框框，这就是终端

### 步骤 5：验证 Node 装好了 + 下载项目依赖
在终端里依次敲下面两行（每敲一行按一次回车）：
```
node -v
npm -v
```
- 能显示版本号（比如 `v20.x.x`）就说明 Node.js 装好了 ✅

接着敲这行，下载项目需要的工具：
```
npm install
```
- 它在干嘛：把博客需要的工具包下载到 `node_modules` 文件夹
- 会滚很多字，**耐心等**，直到出现新的一行能继续打字为止（可能几分钟）
- 报错就截图，记到问题本，晚上集中问

### 步骤 6：把网站跑起来
接着敲：
```
npm run dev
```
- 它会显示一行网址，类似 `http://localhost:5173`
- **按住 Ctrl 点那个网址**，或自己打开浏览器输入 `http://localhost:5173`
- 你就会看到博客首页出现在浏览器里！🎉 这就是"网站在你电脑上跑起来了"

### 步骤 7：逛一逛你的网站
每个页面都点一遍：首页、关于我、学习笔记（点开一篇看看）、项目展示。
> 心里有数：这个网站长什么样、有哪些页面。接下来一个月，你要做的就是**把它彻底搞懂、变成你自己的**。

### 步骤 8：怎么关掉 / 明天怎么再打开
- 关掉：回到终端按 `Ctrl + C`
- 明天再打开：VS Code 打开文件夹 → 开终端 → 敲 `npm run dev`（`npm install` 装过一次就不用再装了）

## 第三部分：认识项目的文件夹（都是干嘛的）

打开左边的 `src` 文件夹，对照下表混个眼熟（**不用背**，后面每天会一个个搞懂）：

| 文件夹 / 文件 | 大白话作用 |
|---|---|
| `main.js` | 整个网站的"总开关"，从这里启动 |
| `App.vue` | 网站的"外框"：顶部导航 + 中间内容 + 底部页脚 |
| `router/` | 路由表：哪个网址显示哪个页面 |
| `components/` | 可复用的小积木（导航栏、笔记卡片、页脚） |
| `views/` | 一个个完整的页面（首页、关于我、笔记…） |
| `data/` | 网站的"内容"（你的资料、笔记、项目都写在这里） |
| `styles/` | 全局的"装修"（颜色、通用样式） |

> `.vue` 结尾的文件叫"**单文件组件**"——一个文件里同时装了这块积木的结构(HTML)、样式(CSS)、逻辑(JS)。
