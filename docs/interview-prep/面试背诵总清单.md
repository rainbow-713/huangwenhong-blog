# 面试背诵总清单（唯一入口）

> 这份是黄雯宏面试准备的**总入口**。背什么、不背什么、按什么顺序，全看这一页。
> 其他文档都由这里指过去，别再到处翻。
>
> **口径基线（所有回答统一遵守）**：
> 1. 部署**只说 GitHub Pages**，不提 Vercel（Vercel 已删，简历和主线题库都已改）。
> 2. 网站页面**只说线上真实有的**：首页、关于我、学习笔记、项目展示。
> 3. 书店是**基于开源模板二次开发**，坦诚说，不吹"独立开发/前后端分离"。
> 4. 概念题背"是什么、为什么"就够；**手写代码实现暂缓**（训练里已暂停）。
